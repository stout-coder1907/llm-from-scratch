# LLM From Scratch 🚀 
day1

A hands-on journey into understanding, implementing, and training Large Language Models from the ground up. This repository tracks my daily progress, implementations, and experiments as I build and deconstruct language models step-by-step.

## 📂 Repository Structure

*   `day1.ipynb` — Initial exploration into tokenization, working with Byte-Pair Encoding (BPE), and text processing foundations.
*   `token_script.py` — A standalone clean implementation of text tokenization utilizing the `tiktoken` library (GPT-2 encoding style).
